1. 基础操作 O(1) 访问

数组是最基本的数据结构。通过下标可以在 O(1) 时间内访问任意元素，但搜索、插入和删除在最坏情况下需要 O(n) 时间。

💡 关键点：数组的连续内存布局使得缓存友好，实际访问速度远快于链表。在算法题中，数组通常是输入的基本形式。

2. 双指针法 Two Pointers

双指针是数组题中最重要的技巧之一。常见变体：

🔹 对撞指针（首尾） —— 一个从头、一个从尾向中间逼近，适用于有序数组的两数之和、回文判断、数组平方排序等。

🔹 快慢指针 —— 快指针探路、慢指针记录，适用于原地移除元素、去重等原地修改类问题。

🔹 滑动窗口 —— 维护一个可变区间 [left, right]，适用于满足某条件的最小子数组、最长子数组等连续子数组问题。

3. 二分查找 Binary Search

在有序数组上，二分查找可以在 O(log n) 时间内定位目标值。核心思想：每次将搜索范围缩小一半。

💡 模板要点：注意 left、right 的初始值和循环不变量。常见的变体包括查找第一个 >= target 的位置（lower_bound）和最后一个 <= target 的位置（upper_bound）。

4. 前缀和 Prefix Sum

前缀和数组 pre[i] = nums[0] + nums[1] + ... + nums[i-1]，可以在 O(1) 时间内回答任意区间的和查询，预处理需要 O(n) 时间。

💡 区间和公式：sum(nums[l..r]) = pre[r+1] - pre[l]。这是处理"连续子数组的和"类问题的利器。

5. 二维数组技巧 2D Array

🔹 螺旋遍历 —— 维护上下左右四个边界，按右 → 下 → 左 → 上的顺序逐步收缩边界。

🔹 二维前缀和 —— 预处理 pre[i][j] 表示从 (0,0) 到 (i-1,j-1) 的子矩阵和，可以 O(1) 查询任意子矩阵的和。

💡 关键：二维问题本质上是嵌套的一维问题，理清行列循环的顺序和边界是解题关键。

6. 常用套路 Common Patterns
🔄
原地修改

利用快慢指针在原数组上覆盖，空间 O(1)。适用于移除元素、去重等。

🧱
分块处理

将数组分成大小为 √n 的块，平衡查询与更新的复杂度。进阶技巧。

🔀
平方后归并

有序数组平方后利用双指针从两端合并，避免排序的 O(n log n)。

📐
模拟边界

螺旋矩阵、蛇形遍历等，核心是维护边界并逐步收缩。

📊
差分数组

前缀和的逆操作，适合批量区间更新、单点查询的场景。

🎯
二分答案

答案具有单调性时，二分答案 + 验证，将优化问题转化为判定问题。
