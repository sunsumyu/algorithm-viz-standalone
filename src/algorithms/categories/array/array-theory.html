理解数组的内存布局、操作与时间复杂度

1. 什么是数组 Array Basics

数组（Array）是最基础的数据结构之一，它将同类型元素存储在连续的内存空间中。数组的每一个元素都可以通过下标（index）在 O(1) 时间内直接访问。

数组的特点：
• 连续存储 —— 元素在内存中首尾相连
• 固定大小（静态数组）—— 声明后容量不变
• 随机访问 —— 通过下标 O(1) 直达目标

2. 内存布局 Memory Layout

数组在内存中占据一段连续的地址空间。假设数组首地址为 base，每个元素占 size 字节，则第 i 个元素的地址为：

addr(i) = base + i × size

内存中的数组 arr = [3, 5, 7, 11, 15]
0x003
0x045
0x087
0x0C11
0x1015
addr(3) = 0x00 + 3 × 4
= 0x0C

正因为地址可以直接计算，所以无需遍历就能访问任意元素，这就是 O(1) 随机访问的本质。

3. 下标访问 O(1) Access

数组最强大的操作是随机访问：给定下标 i，通过硬件级的地址计算，CPU 可以在常数时间内读取或写入该位置。

arr[i] 的执行过程：
• 取数组首地址 base
• 计算偏移量 i × size
• 从地址 base + i * size 读取数据

这也是为什么数组下标从 0 开始：当 i = 0 时，偏移量为 0，直接指向首元素。

4. 基本操作复杂度 Complexity

数组的不同操作有着截然不同的时间代价。访问是 O(1)，而搜索、插入和删除通常需要 O(n)。

操作时间复杂度说明
访问 arr[i]O(1)地址计算直达
搜索 targetO(n)线性扫描逐个比较
插入（中间）O(n)后续元素依次右移
删除（中间）O(n)后续元素依次左移
5. 常用技巧 Techniques
双指针

用两个指针从不同方向逼近，解决有序数组求和、原地移除等经典问题。时间 O(n)。

滑动窗口

维护一个动态区间 [left, right]，用于连续子数组/子串问题。

前缀和

预处理 prefix[i] = sum(arr[0..i-1])，将区间求和从 O(n) 降到 O(1)。

二分查找

在有序数组中每次排除一半，O(log n) 定位目标值。

6. JS 中的数组 JavaScript Array
Array 是动态数组

JavaScript 的 Array 本质上是动态数组（Dynamic Array），容量不够时自动扩容（通常翻倍）。这使得 push/pop 尾部操作均摊 O(1)，但 unshift/shift 或中间插入删除仍为 O(n)，因为需要移动元素。
