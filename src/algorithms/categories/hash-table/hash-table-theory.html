1. 什么是哈希表 Hash Table

哈希表（Hash Table）是一种根据键（Key）直接访问值（Value）的数据结构。它的核心思想是：通过一个哈希函数把键映射到数组的某个下标，从而实现近乎 O(1) 的插入、查找与删除。

2. 哈希函数 Hash Function

哈希函数接收任意类型的键，返回一个固定范围内的整数作为数组下标。好的哈希函数应当：

• 计算快速 —— O(1) 时间内完成
• 均匀分布 —— 让键尽可能散开，减少冲突
• 确定性 —— 相同的键永远得到相同的下标

本演示使用最简单的哈希函数：hash(key) = key % size，其中 size = 7。例如 hash(19) = 19 % 7 = 5。

3. 冲突处理 Collision Resolution

当两个不同的键被哈希到同一下标时，就发生了冲突（collision）。常见的处理策略有两种：

链地址法（Chaining）

每个桶保存一个链表（或数组），所有哈希到该桶的元素都追加到链表中。JavaScript 的 Map 在内部遇到冲突时即采用类似策略。

开放寻址法（Open Addressing）

冲突时按某种探测序列（线性、二次、双重哈希）在表中寻找下一个空位。Python 的 dict 使用开放寻址。

4. 时间复杂度 Complexity

哈希表在平均情况下提供 O(1) 的插入、查找和删除性能；但在最坏情况下（所有键哈希到同一桶），会退化为 O(n)。

5. JS 中的哈希表结构 Array / Set / Map
Array

下标为整数键，可视为最朴素的哈希表：arr[i] = value。

Set

只存键（无值），用于快速判重：set.has(x) 平均 O(1)。

Map

真正的键值对哈希表，键可以是任意类型：map.get(k) 平均 O(1)。
