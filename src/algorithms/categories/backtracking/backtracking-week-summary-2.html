回溯周末总结（二）

切割、子集与同层去重的阶段性总结

切割问题

切割问题把字符串的每个切割点看作选择。startIndex 表示下一段从哪里开始，终止条件通常是 startIndex 到达字符串末尾。

子集问题

子集问题不是只在叶子节点收集答案，而是进入每个节点都收集当前 path。

同层去重

nums.sort((a, b) => a - b);
for (let i = start; i < nums.length; i++) {
  if (i > start && nums[i] === nums[i - 1]) continue;
}
