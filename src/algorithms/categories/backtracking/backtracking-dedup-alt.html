回溯算法去重问题的另一种写法

从 used 数组与本层集合两个角度理解回溯去重

树层去重

排序后相同元素如果在同一层被重复选择，会产生重复答案，所以要跳过后一个相同值。

if (i > start && nums[i] === nums[i - 1]) continue;

排列去重

排列题常用 used 数组判断前一个相同元素是否已经在当前路径中。

if (i > 0 && nums[i] === nums[i - 1] && !used[i - 1]) continue;

不排序去重

递增子序列这类必须保留原顺序的问题，使用每层 Set。

const usedThisLevel = new Set(); if (usedThisLevel.has(nums[i])) continue; usedThisLevel.add(nums[i]);
