回溯算法的递归模板、搜索树与剪枝方法

回溯的本质

回溯是递归控制下的暴力搜索：沿一条路径不断做选择，遇到不满足条件或完成答案时返回上一层，撤销选择，再尝试下一条分支。

路径 path 选择列表 choices 终止条件 撤销选择

回溯三部曲

  1. 确定递归函数参数：通常包含 startIndex、used、path、棋盘坐标等。
  2. 确定终止条件：收集答案、越界、无候选、满足目标。
  3. 确定单层搜索逻辑：for 循环枚举选择，递归后回溯。

通用模板

function backtrack(参数) { if (终止条件) { result.push([...path]); return; } for (const choice of choices) { if (剪枝条件) continue; path.push(choice); backtrack(下一层参数); path.pop(); } }

题型差异

题型核心参数关键点 组合/切割/子集 startIndex 下一层只能从后面选 排列 used 每层可从头扫描，跳过已用 棋盘问题 row/col/board 二维约束校验
