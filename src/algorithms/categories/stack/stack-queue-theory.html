栈与队列理论基础

理解 LIFO 和 FIFO 两种数据结构
核心概念：栈是后进先出（LIFO），队列是先进先出（FIFO）。切换模式观察两种结构在 push/pop 和 enqueue/dequeue 操作下的差异。
1. 栈 (Stack) LIFO

栈是一种后进先出（LIFO, Last In First Out）的线性数据结构。只能在一端（栈顶）进行插入和删除操作。

核心操作：push(x) 将元素压入栈顶，pop() 弹出栈顶元素，top() 查看栈顶元素，empty() 判断栈是否为空。

2. 队列 (Queue) FIFO

队列是一种先进先出（FIFO, First In First Out）的线性数据结构。一端入队（队尾），另一端出队（队头）。

核心操作：enqueue(x) 将元素加入队尾，dequeue() 从队头移除元素，front() 查看队头元素，empty() 判断队列是否为空。

3. 应用场景 Applications

栈和队列在计算机科学中有着广泛的应用场景：

栈的典型应用

• 函数调用栈 —— 递归调用与返回
• 浏览器历史 —— 前进 / 后退
• 括号匹配 —— 编译器语法检查
• 撤销操作 —— 编辑器 Undo

队列的典型应用

• BFS 广度优先搜索 —— 层序遍历
• 任务调度 —— 操作系统进程队列
• 消息队列 —— 异步处理
• 打印机队列 —— 先来先服务

4. 时间复杂度 Complexity

栈和队列的所有基本操作都是 O(1)，因为操作只发生在固定位置，不需要遍历或搜索。

操作栈 Stack队列 Queue
插入push O(1)enqueue O(1)
删除pop O(1)dequeue O(1)
查看顶端/前端top O(1)front O(1)
判空empty O(1)empty O(1)
5. JS 中的栈和队列 Array / LinkedList
Array 作为栈

arr.push(x) 入栈，arr.pop() 出栈，均在尾部操作，O(1)。

Array 作为队列

arr.push(x) 入队，arr.shift() 出队。shift 为 O(n)。

LinkedList 队列

用链表实现队列，入队和出队均为 O(1)，避免 shift 的性能问题。

双端队列

deque.push/pop/shift/unshift 均可 O(1)（链表实现），灵活支持两端操作。
