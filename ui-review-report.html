关键问题 按优先级排列

🔴 无设计令牌系统 — 314 个文件各自为政

CRITICAL

每个可视化文件独立定义 ~200 行 CSS。512 处 backdrop-filter: blur(18px) saturate(160%)、462 处 rgba(20, 18, 38, .55) 背景、1537 处 querySelector 调用分散在各文件中。修改全局主题需要编辑所有文件。

✅ 修复方案

/* src/styles/tokens.css */
:root {
  /* Spacing — 4px base */
  --sp-1: 4px;  --sp-2: 8px;  --sp-3: 12px;
  --sp-4: 16px; --sp-5: 20px; --sp-6: 24px;
  --sp-8: 32px; --sp-10: 40px;

  /* Typography — modular scale (1.2 ratio) */
  --fs-xs: 11px;  --fs-sm: 13px;
  --fs-md: 16px;  --fs-lg: 19px;
  --fs-xl: 23px;  --fs-2xl: 28px;

  /* Glass surfaces */
  --glass-bg: rgba(20, 18, 38, .55);
  --glass-blur: blur(18px) saturate(160%);
  --glass-border: 1px solid rgba(255, 255, 255, .08);
  --glass-radius: 16px;

  /* Shared card */
  .glass-card {
    background: var(--glass-bg);
    backdrop-filter: var(--glass-blur);
    border: var(--glass-border);
    border-radius: var(--glass-radius);
    box-shadow: 0 12px 40px rgba(0, 0, 0, .35);
  }

🔴 无障碍访问完全缺失 — 0 / WCAG 2.1 AA

CRITICAL

整个项目：0 个 ARIA 属性、0 个 role、0 个 alt、0 个 tabindex。键盘用户无法操作任何控件。屏幕阅读器无法解读算法步骤。颜色对比度未验证。

✅ 修复方案

<!-- 1. 为控制区域添加 ARIA -->
<div class="controls" role="toolbar" aria-label="动画控制">
  <button aria-label="上一步" aria-keyshortcuts="ArrowLeft">◀</button>
  <button aria-label="播放/暂停" aria-pressed="false">▶</button>
  <button aria-label="下一步" aria-keyshortcuts="ArrowRight">▶</button>
</div>

<!-- 2. 可视化区域添加 live region -->
<div class="viz-area" role="region" aria-label="算法可视化">
  <div aria-live="polite" class="sr-only">{{currentStep.message}}</div>
</div>

<!-- 3. 添加 tabindex 使元素可聚焦 -->
<div class="cell" tabindex="0" role="gridcell"
     aria-label="值 42，已排序">42</div>

🟡 字体大小不成模块化比例 — 15 种值

HIGH

13px（659 次）和 12px（484 次）为主力，但还有 12.5px（131 次）、11px、14px、22px 等。12px 和 12.5px 的差异肉眼无法分辨，却增加了维护成本。建议使用 4 级模块化比例。

✅ 修复方案

/* 4 级模块化比例 (基于 1.25) */
--fs-xs: 11px;   /* 标签、辅助文本 */
--fs-sm: 13px;   /* 正文、输入框 */
--fs-md: 16px;   /* 标题、强调 */
--fs-lg: 20px;   /* 大标题 */

🟡 Border-Radius 过于分散 — 3 个主要值 + 12 个次要值

HIGH

10px（475）、12px（416）、16px（386）三个值几乎等量，加上 8px、14px、6px、11px 等 12 个其他值。应统一为 3 级：sm(8px) / md(12px) / lg(16px)。

🟡 间距混合非标准值 — 14px 和 10px 偏离 4px 网格

HIGH

14px 出现 1452 次，10px 出现 1462 次。这些不是 4 的倍数。应统一到 4px 网格：10px → 8px 或 12px，14px → 12px 或 16px。

🔵 509 处 innerHTML — 性能与安全风险

MEDIUM

仅 47 处使用 DOM 复用模式（cellGrid / DOM reuse），其余 344 处为 innerHTML 重建。在动画步进时频繁重建 DOM 导致不必要的 reflow，且存在 XSS 注入风险。

✅ 修复方案 — 已在 nqueen / sudoku 中验证

// ❌ Before: 每步重建
this.boardEl.innerHTML = cells.map(c =>
  `<div class="cell">${c.value}</div>`).join('');

// ✅ After: DOM 复用 + class 切换
this.cells.forEach((el, i) => {
  el.textContent = String(cells[i].value || '');
  el.classList.toggle('highlighted', cells[i].highlight);
  el.classList.toggle('leaving', cells[i].leaving);
});
