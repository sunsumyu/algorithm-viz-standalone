/improve-codebase-architecture 阶段：第二轮深度重构候选评审

「不同路径」与通用可视化体系 · 深度架构审查报告

针对当前「不同路径」双端模板（精讲版 vs 极速版）及多模型生态，识别浅层模块摩擦，提供深度模块化演进候选方案。

当前已解耦成果：
YAML 规范事实源 (6款模型)
通用推导引擎 (UniversalStageEngine)
无损状态路由 (VisualizerStateRouter)

当前架构摩擦点诊断 (Architectural Friction Analysis)

1. 双端 UI 视觉渲染存在大量内联

两端 HTML 内依然包含手写的 SVG 递归树自适应布局 (~240行) 与网格格点 DOM 拼接逻辑，视觉表现层缺乏通用适配器 (VisualAdapter)。

2. 播放控制器与时间轴逻辑重复

unique-paths.html 与 lite.html 各自重复维护了定时器管理、边界自动暂停、滑块拖拽及倍速调节机制。

3. 页面壳层可进一步收敛为通用容器

目前页面已经能够通过 ?model=... 动态装配 6 种算法模型，可正式提升为单一标准通用探索容器，消除题目特化的 HTML 壳。

候选方案 1 推荐强度：Strong (最高收益)

提炼视觉适配器深模块 (Grid & RecursionTree VisualAdapter)

涉及文件： src/core/renderers/grid-visual-adapter.ts, unique-paths.html, unique-paths-lite.html

问题 (Problem)： 极速版与精讲版中均内嵌了约 300 行 DOM/SVG 拼接代码（包括复杂递归树的动态节点跨度计算、高亮连线与网格格点物理状态徽章）。任何视觉样式修改需要跨两个 HTML 文件同步。

解决方案 (Solution)： 构建统一的 GridVisualAdapter 与 RecursionTreeAdapter 深度模块，对外暴露纯净接口 adapter.render(container, stepSnapshot)，内部封装坐标计算、SVG 节点连接、动画平滑过渡与自适应缩放。

收益 (Leverage & Locality)： 彻底剥离 HTML 视图中的绘图脏逻辑（减少 ~350 行内联代码）；使后续所有的网格 DP（如最小路径和、最大正方形等）获得即开即用的高品质视觉渲染。

候选方案 2 推荐强度：Strong

时间轴与自动播放控制器深模块 (PlaybackTimelineController)

涉及文件： src/core/playback-timeline-controller.ts, unique-paths.html, unique-paths-lite.html

问题 (Problem)： 播放/暂停状态机、自动步进定时器 (`setInterval`)、倍速切换、滑块进度同步、步长溢出校验等在精讲版与极速版中各自实现，存在定时器泄露与速度同步不一致的潜在边界缺陷。

解决方案 (Solution)： 将播放控制提炼为单一职责的 PlaybackTimelineController 类，对外提供 play() / pause() / toggle() / stepForward() / stepBackward() / seek(index) / setSpeed(ms)，内置定时器生命周期管理与事件监听。

收益 (Locality & Leverage)： 保证所有算法画板具有 100% 一致的播放交互行为，支持在单元测试中对其进行精确的虚拟时间轴测试。

候选方案 3 推荐强度：Worth exploring

通用算法演化探索画板 (Universal Stage Explorer Container)

涉及文件： stage-explorer.html, stage-explorer-lite.html

问题 (Problem)： 页面虽然已实现通过 `?model=...` 动态装载 6 个模型，但文件名仍保留为特定题目的 `unique-paths.html`。新算法开发者可能会误以为需要为每道题复制一份 HTML 文件。

解决方案 (Solution)： 将主容器命名规范化为通用的 stage-explorer.html 与 stage-explorer-lite.html，在根目录下保留 unique-paths.html 作为平滑向后兼容别名。

收益 (Navigability)： 代码库概念更加清晰，彻底确立「编写一个 YAML 规范 = 自动获得全套精讲/极速双画板」的高效开发者体验。

首席架构师推荐行动序列 (Recommended Execution Order)

1
首选落地：提炼视觉适配器深模块 (Grid & RecursionTree VisualAdapter)

消除 HTML 内最后一大块内联逻辑（240行 SVG 树与网格 DOM 渲染），使网格与树形表现层完全独立于业务页面。

2
次选落地：统一时间轴播放控制器 (PlaybackTimelineController)

封装自动播放、倍速调节与步进状态机，消灭双端重复定时器管理。
