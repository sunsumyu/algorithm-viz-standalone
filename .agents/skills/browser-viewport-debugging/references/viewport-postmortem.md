# 视口缩小事故根因分析 (Viewport Post-Mortem)

## 故障现象
UI 调试截图出现“界面挤在左上角，右下大面积空白”的失衡状态。

## 事故根因
1. **Puppeteer 默认视口限制**：
   Puppeteer MCP 的 `puppeteer_screenshot` 若未显式传参，默认参数为 `{ "width": 800, "height": 600 }`。每次调用会强制将 Chrome 视口重设为 800×600。
2. **物理窗口与视口错位**：
   桌面窗口通常为 1920×1080 或更高分辨率最大化状态。此时外层 Chrome 窗口很大，但视口被锁定在左上角 800×600 区域内。
3. **响应式断点被破坏**：
   系统左右双栏排布依赖 Tailwind CSS 的 `lg:flex-row`（断点为 1024px）。当视口降为 800px 时，界面退化为移动端上下堆叠（`flex-col`），造成布局失真。
